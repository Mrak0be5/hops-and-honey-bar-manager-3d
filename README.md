# Хмель & Мёд — 3D бар-менеджер

Небольшой изометрический менеджер бара на React, TypeScript и Three.js. Посетители сами находят свободный стол, садятся на стулья, заказывают напитки, пьют, платят и уходят. Бармен принимает заказы, наливает напитки, разносит их и убирает грязные кружки.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:4187`.

## Развитие бара

- скорость передвижения бармена;
- скорость принятия заказа;
- скорость приготовления напитков;
- скорость уборки кружек;
- ассортимент напитков и средний чек;
- реклама и частота появления гостей.

Состояния гостей и бармена показываются эмодзи над персонажами. Верхняя панель содержит паузу, ускорение времени, звук и магазин улучшений. Интерфейс адаптирован для настольных и мобильных экранов.

## Проверка

```bash
npm test
npm run build
npx playwright test
```

Vitest проверяет симуляцию и геометрию посадки. Playwright проверяет desktop/mobile-интерфейс, полный цикл обслуживания и сохраняет прямые WebGL-кадры для визуального контроля.

## Графика

Сцена использует ортографическую камеру, мягкие тени, процедурные low-poly модели, анимированные позы и эффекты действий. UI-иконки и иконки валют созданы встроенным GPT Image 2 как единый атлас. Исходник находится в `art-source/bar-icon-atlas-source.png`, WebP-файлы — в `public/assets/ui`, скрипт нарезки — `tools/slice_icon_atlas.py`.
