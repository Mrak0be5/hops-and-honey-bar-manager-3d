# Бордель у Кристофера — 3D бордель-менеджер

Изометрический менеджер борделя на React, TypeScript и Three.js (ветка `theme/brothel-christopher`). Гости пьют в зале у Кристины, затем могут уйти в стрип, комнату удовольствий или зал оргии.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:4187`.

## Развитие

- скорость и шоу Кристины при подаче напитков;
- ассортимент (микс пива и adult-коктейлей) и эскалация подачи;
- комнаты: стрип / секс / оргия + апгрейды персонала;
- реклама и частота гостей.

## Проверка

```bash
npm test
npm run build
npx playwright test
```
