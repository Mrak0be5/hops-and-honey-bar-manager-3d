# Hops & Honey — Flame Edition

Самостоятельный Flutter + Flame порт браузерного менеджера бара. Версия использует
процедурную изометрическую сцену, детерминированную Dart-симуляцию, клеточную
навигацию посетителей и адаптивный HUD для телефонов 9:16 и desktop.

```powershell
flutter pub get
flutter run -d chrome
flutter test
flutter build web --release
```

Web-релиз создаётся в `build/web`.
